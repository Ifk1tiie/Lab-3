## Descripción

Este proyecto consiste en el desarrollo de un sistema web para el registro de aspirantes utilizando HTML5, PHP y Bootstrap.

El sistema permite ingresar los datos personales de un aspirante mediante un formulario, validar la información recibida y subir una fotografía al servidor.

También se aplican funciones de saneamiento, normalización y validación de datos del lado del servidor.

---

## Objetivo

Desarrollar un formulario web utilizando PHP y Bootstrap que permita registrar los datos de un aspirante, validar la información ingresada y almacenar de forma segura su fotografía en el servidor.
